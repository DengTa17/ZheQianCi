# 折千词

> 千词可折，一词一心

一个纯前端、单文件可分享的背单词小程序。数据保存在浏览器本地 IndexedDB，无需后端，双击 `折千词.html` 就能使用。

## 功能

- 开始学习 / 复习 / 导入单词
- 按反应时间计分：秒答加分，慢答扣分；达到锚定值才算掌握
- 复习列表带记忆进度圆环、英 / 美双音标、词性与释义
- 三套界面主题：默认暖色 / 科幻科技感 / 小清新
- 难度曲线：用滑条调节每个词的目标阈值
- 手动导入 / 拍照 OCR 导入
- 导入时可自动获取音标、词性、例句，也可接自定义模型生成例句
- 内置 50 个四级高频词

## 使用

直接双击根目录的 `折千词.html` 即可打开。发给别人时，只发这个单文件也能用。

GitHub Pages 在线版会自动进入 `折千词.html`。

## 说明

核心学习、复习、计分、主题、难度和本地数据功能可离线使用。拍照 OCR、在线词典补全、自定义模型生成例句等功能需要联网。

重要数据请在应用内使用“导出备份”保存，换浏览器或清缓存可能导致本地数据丢失。
