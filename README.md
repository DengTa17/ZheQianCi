# 折千词

> 千词可折，一词一心

一个纯前端、单文件可分享的背单词工具。数据保存在浏览器本地 IndexedDB，无需后端，双击 `折千词.html` 就能使用。

- `index.html`：DT灯塔风格的产品介绍页
- `折千词.html`：完整应用

## 功能

- 开始学习 / 复习 / 导入单词
- 按反应时间计分：秒答加分，慢答扣分；达到锚定值才算掌握
- 复习列表带记忆进度圆环、英 / 美双音标、词性与释义
- 三套界面主题：默认暖色 / 科幻科技感 / 小清新
- 难度曲线：用滑条调节每个词的目标阈值
- 手动导入 / 拍照 OCR 导入
- GLM-OCR 识图 + DeepSeek 去重纠错
- 有道在线词典双语例句与国内可用发音方案
- AI 增量解析，30 词分批、最多两批并行
- 复习列表支持电子书式拖拽翻页遮挡
- 可接入自定义 OpenAI 兼容模型
- 内置 50 个四级高频词

## 使用

直接双击根目录的 `折千词.html` 即可打开。发给别人时，只发这个单文件也能用。

GitHub Pages 在线版首先展示产品介绍页，可从页面中的“打开应用”进入 `折千词.html`。

智谱文本、智谱 OCR 与 DeepSeek 的 API Key 不会写入源码。需要对应能力时，在应用的“AI 模型设置”中填写，凭据仅保存在当前浏览器 `localStorage`。不配置 Key 时，手动导入、本地 OCR、在线词典、发音、学习与复习功能仍可使用。

## 说明

核心学习、复习、计分、主题、难度和本地数据功能可离线使用。GLM-OCR、在线词典补全、AI 解析和自定义模型生成例句等功能需要联网。

重要数据请在应用内使用“导出备份”保存，换浏览器或清缓存可能导致本地数据丢失。
